# Kuyum Studio

Kuyum Studio prepares product photos and exports PDF catalogues for jewellery wholesalers. The standalone project includes a real ring catalogue, an image-processing example, tests and sample files.

- [View the project and catalogue preview](https://github.com/SameTeke/kuyum-studio)
- [Open the PDF with 16 photographed rings](https://github.com/SameTeke/kuyum-studio/blob/main/sample-catalogue.pdf)
- [Run the Node.js batch converter](https://github.com/SameTeke/kuyum-studio/tree/main/batch-example)
