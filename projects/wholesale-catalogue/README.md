# Bilingual wholesale catalogue

I worked on a pilot for wholesalers preparing product pages in Turkish and English. A buyer browsing either language should be able to recognise the same item from its photo and description. The editorial challenge is keeping those versions consistent as new products enter the catalogue.

## What an editor reviews

The workflow brings a product photo and the available product information together. It prepares a name, short description and longer description for each language. An editor can review the two drafts alongside the photograph and flag a detail that needs confirmation.

For example, if a photograph shows a pendant from one angle, a reader may still have a question about its reverse side. A useful review records the open question before the text goes to a buyer. This is an illustrative editorial example.

## Project scope

The work focuses on preparing and checking bilingual catalogue content. Python, PowerShell and JavaScript support the offline preparation and validation steps. The pilot produces drafts for human review.

For the desktop application that prepares product photos and exports the finished visual catalogue, see [Kuyum Studio and its sample PDF](../kuyum-studio/).
